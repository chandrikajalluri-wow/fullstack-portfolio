1. User enters a website URL in the browser.

2. DNS (Domain Name System) converts the domain name (e.g., example.com) into the server’s IP address.

3. The browser sends an HTTP GET request to that IP address.

4. The server receives and processes the request.

 - It may access a database or external API if needed.

5. The server sends a response back (HTML, JSON, files, etc.).

6. The browser renders the response and displays the webpage.

# HTTP vs HTTPS

## HTTP

- HyperText Transfer Protocol

- Used for transferring data over the web

- Defines how requests and responses look

- Not encrypted

- Not secure

## HTTPS

- HyperText Transfer Protocol Secure

- Secure version of HTTP

- Uses SSL/TLS encryption

- Data is protected during transmission

- Used for login, payments, sensitive data

## Common HTTP Methods

- GET — Retrieve data

- POST — Send data

- PUT — Update data fully

- PATCH — Partially update

- DELETE — Remove data
